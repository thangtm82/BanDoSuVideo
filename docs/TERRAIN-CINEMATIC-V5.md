# Terrain Cinematic v5 — Engine upgrade

This optional rendering pack updates the **external H2 Terrain Engine** (specifically `packs/terrain/world.js`) and is **not** an overhaul of the C# WPF renderer. AI Terrain Scene Builder automatically sets `graphics: "cinematic"` for newly generated worlds only if the selected imported engine contains the V5 rendering code.

## What's in the upgraded engine

- New `graphics: "cinematic"` mode with procedural fine detail localized around hills, terrain-slope tint, MeshStandardMaterial ground, ACES tonemapping, rock color variation, subdued foliage, village roofs, more directional lighting.
- Compatible defaults: existing worlds without `graphics: "cinematic"` keep the prior rendering mode.
- Optional knobs: `terrainDetail` (0 to 1.8, default 0.85), `exposure` (default 1.22), and existing `ambient`, `sun`, `ground`, `haze`, `treeColors`, `rockColor`.
- Terrain-specific content remains schematic unless verified DEM and historical data are supplied.

## Installing the external engine

Use the separately distributed `H2-Terrain-Cinematic-v5.zip`, generated by patching the user-supplied H2 Terrain Studio kit.

1. In Environment Manager import the full ZIP as a **new engine** (do not overwrite the working legacy engine).
2. Install its Node dependencies through Environment Manager. The ZIP intentionally excludes `node_modules`.
3. Bind the project to the new engine; check the project's `.bandosu-engine.json` and back up `story/shots.json`.
4. Re-generate scenes using AI Terrain Scene Builder or manually opt in for a test project by adding `"graphics":"cinematic"` to the world.
5. Render a **Bảng ảnh tổng hợp** first and check visually before full exports.

## Validation and risks

- `node --check packs/terrain/world.js` validates JavaScript syntax. Build/CI tests validate only C# integration and the preset compatibility gate.
- Screenshot fidelity/performance must be confirmed on the user's actual Windows/Chromium/RTX 3060 setup. Current tests do not constitute a Three.js rendering acceptance test.
- This release does **not** provide architectural reconstruction, historically verified landforms, real photogrammetric textures, physically simulated water, or AI Vision.

## Scope of changes in BanDoSuVideo

Changes in the C# repository only toggle the preset for an upgraded imported engine. The new rendering implementation is shipped separately in the external engine ZIP; it is not copied into `BanDoSu.Core`.
